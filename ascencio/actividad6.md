# Propuesta conceptual de videojuego
Un videojuego 2D de un vendedor de comida que viaja por diferentes países que debe preparar y entregar una cantidad determinada de pedidos antes de que se acabe el tiempo y cada país tendrá su propia comida, ambiente, personajes, animales y problemas.

## Mecánica principal
La mecánica principal consiste en preparar y entregar pedidos mientras se enfrentan diferentes problemas que aparecen durante el nivel.
El jugador debe alcanzar una cantidad de pedidos para completar el nivel, mientras prepara la comida ocurren eventos inesperados que interrumpen el proceso y lo hace mas dinamico y un poco retador dependiendo la dificultad del nivel.

## Objetivo del jugador
El objetivo es completar la cantidad de pedidos en cada nivel antes de que se termine el tiempo, se pueden conseguir mas puntos si completa más pedidos, tarda menos tiempo y resuelve correctamente los problemas que aparecen.
Al completar un nivel, se desbloquea un nuevo país con una nueva comida, ambientación y situaciones.

## Reglas básicas
- Cada nivel tiene una cantidad mínima de pedidos que se deben completar.
- Los pedidos deben prepararse correctamente.
- El jugador tiene un tiempo limitado para completar el objetivo.
- Los problemas pueden hacer perder tiempo o ingredientes.
- El jugador debe resolver los inconvenientes para continuar trabajando.
- Los errores pueden reducir la puntuación.
- Cada país presenta diferentes escenarios, comidas, personajes, animales y situaciones.
- Al completar la cantidad necesaria de pedidos se termina el nivel.
- El jugador puede arrojar cosas que se encuentre.
- El jugador puede utilizar distintas herramientas para defenderse de los enemigos.
- Si la barra de vida llega a cero el jugador pierde el nivel.

## Experiencia buscada
Quiero que el jugador sienta rapidez, presión, diversión y sorpresa. La preparación de pedidos le pone presión por el tiempo, los enemigos y situaciones inesperadas hacen que el jugador tenga que reaccionar rapido antes de perder.

## Coherencia del diseño
La idea junta la preparación de comida con elementos de acción, aunque el jugador tenga que atender pedidos, también tiene que defender su puesto y resolver problemas.

Cada país mantiene estas mecánicas, pero cambia la comida, el escenario, los enemigos y las situaciones, esto hace que cada nivel se sienta diferente sin cambiar completamente como se juega.

### MDA
**Mecánicas:** preparar comida, entregar pedidos, moverse, combatir, usar armas, conseguir mejoras y sobrevivir.

**Dinámicas:** presión por el tiempo, combate, y situaciones inesperadas.

**Estética:** humor, acción, caos, sorpresa y diferentes ambientes según el país.
